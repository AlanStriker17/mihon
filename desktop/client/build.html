Build Mihon Desktop for Windows

Get a Windows installer for the Mihon desktop client. The installer must be built on Windows; a browser or Linux machine cannot compile a Windows .exe by itself.

Choose a Windows package

Downloads a ZIP containing Mihon.exe and its bundled runtime. Extract it and run Mihon.exe; no installer or WiX is needed.

Build it in GitHub Actions

  1. Open the Windows build workflow; pushes to the build branch automatically build both portable ZIP and EXE packages.
  2. For a manual run, choose portable in the package format menu.
  3. Wait for the run to finish successfully.
  4. Open the run and download the mihon-desktop-windows-portable-exe artifact.

You need to be signed in to GitHub to download the workflow artifact. Manual format selection requires the workflow to be enabled on the repository's default branch.

Build on your Windows PC

With JDK 21 installed, run the PowerShell script from the repository root. It defaults to the portable ZIP, which does not require WiX:

.\desktop\client\Build-Mihon.ps1 -PackageType portable

Choose exe or msi instead only if WiX Toolset is installed and available on PATH.

View the Windows build script

This creates the current incremental desktop client, not a feature-complete Windows port. Existing Android extension APKs are not compatible with the desktop client.
