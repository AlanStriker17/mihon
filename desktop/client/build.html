Build Mihon Desktop for Windows

Get a Windows installer for the Mihon desktop client. The installer must be built on Windows; a browser or Linux machine cannot compile a Windows .exe by itself.

Build it in GitHub Actions

  1. Open the Windows build workflow and select Run workflow.
  2. Wait for the run to finish successfully.
  3. Open the run and download the mihon-desktop-windows artifact. It contains the installer.

You need access to the repository and must be signed in to GitHub to start the workflow and download its artifact.

Build and download via GitHub Open repository

Build on your Windows PC

Download the repository, install JDK 21, then run Build-Mihon.ps1 from the checkout. The script builds the installer and opens its output folder.

Or run this in PowerShell from the repository root:

.\gradlew.bat :desktop:client:packageWindowsExe --no-daemon

View the Windows build script

This creates the current incremental desktop client, not a feature-complete Windows port. Existing Android extension APKs are not compatible with the desktop client.
